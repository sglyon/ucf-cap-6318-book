Step 1: Install uv¶

  • uv is a single, very fast tool that replaces pip, virtualenv, pyenv, and poetry for Python projects

  • It manages the Python interpreter itself, project dependencies, and virtual environments all in one place

  • The first step is to install uv

Task: Install uv¶

  • Windows: open PowerShell and run powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"

  • Mac/Linux: Open terminal and run curl -LsSf https://astral.sh/uv/install.sh | sh (it is safe -- I promise ;))

Task: Verify the install¶

Open a fresh terminal (PowerShell or Terminal) and run

uv --version

You should see something like this (the version number may be different for you):

$ uv --version
uv 0.9.7

Congratulations! You have successfully installed uv and are ready to move on to the next step!

Step 2: Set up the course environment with uv sync¶

  • With uv installed we are now ready to set up our Python environment

  • uv keeps a dedicated virtual environment per project, described by a pyproject.toml file (and locked precisely in a uv.lock file)

  • The course repository already ships with a pyproject.toml that lists every package we’ll need this semester (numpy, pandas, matplotlib, networkx, and more)

  • To install exactly those packages -- and only those packages -- we run uv sync from inside the repository

Task: Run uv sync¶

Open a terminal, cd into the folder containing the course repository (the one with pyproject.toml in it), and run

uv sync

uv will download the right version of Python (if you don’t already have it), create a .venv folder holding a virtual environment, and install every dependency listed in pyproject.toml at the exact version recorded in uv.lock

Task: Launch Jupyter Lab with uv run¶

  • uv run <command> executes <command> inside the project’s virtual environment, without you needing to manually “activate” anything

  • Launch Jupyter Lab by running

uv run jupyter lab

A web browser should pop open with the Jupyter Lab interface (should look similar to what I’m using)

Step 3: Install Visual Studio Code¶

  • While we can and will use Jupyter Lab directly for our lecture notes, it is also helpful to have the ability to edit and run Python code in a more full-featured editor

  • For this we will use Visual Studio Code (VSCode)

  • VSCode is a free, open-source, cross-platform editor that has a large community of users and developers

  • It also has great support for Python

  • Learning how to use a general purpose text editor will help you in the long run

    • You can use it for Python, Julia, R, C, C++, etc.

    • You can use it for writing papers, taking notes, etc.

Note on VS Code alternatives: There are several popular forks/alternatives to VS Code that provide enhanced features, particularly for AI-assisted coding:

  • Cursor: An AI-first code editor built on VS Code with enhanced AI capabilities

  • Windsurf: Another AI-powered editor with advanced coding assistance features

These alternatives generally maintain compatibility with VS Code extensions (including the Python extension), so you can use any of them for this course if you prefer. The instructions below will work for VS Code and most of its forks.

Task: Download/Install VS Code¶

Download and install VSCode from here

Follow all system prompts and accept default options

Open/launch VSCode

Task: Install the Python extension¶

  • VSCode has a large ecosystem of extensions that add functionality to the editor

  • We will install the official Python extension to add Python support to VSCode

In VSCode, click on the “Extensions” icon in the left-hand toolbar (looks like a box with four squares in it)

Search for “Python” and click the “Install” button on the “Python” extension (published by Microsoft)

Task: run Python code in VSCode¶

  • We can now run Python code in VSCode

  • Open a new file in VSCode (File -> New File)

  • Type the following code into the file:

print("Hello world!")

  • Save the file as hello.py in a location you can find later

  • Press Ctrl + Shift + P (or Cmd + Shift + P on Mac) to open the command palette

  • Type “Python” and select “Python: Run Python File in Terminal”

  • You should see the output of the code show up in a new terminal window within VS Code

Task: run code with shift + Enter¶

Go back to hello.py and add the code

import numpy as np
n = 5
P = np.random.rand(n, n)

Then, put your cursor on the line that contains import numpy and press shift and enter at the same time

This will start a new interactive Python session within your VS Code session and execute the code for you

It will also move your cursor down to the n = 5 line. Press shift + enter again (repeatedly) to execute the remaining lines

Open Notebooks Locally¶

  • You should view/follow along with lectures on the your computer

  • Being able to run code on your machine is critical for success in this course and will allow you to take skills with you after the course

Task: Download notebooks¶

  • Go to the course website and download the notebooks for the first week

  • Move the downloaded folder from your “Downloads” folder to wherever you’d like to store materials for the semester

  • Follow the instructions above to uv sync the environment, then start Jupyter Lab with uv run jupyter lab

  • Inside your local Jupyter Lab instance (in your web browser), navigate to where you copied the “Handouts” folder and open up this notebook

Task: Open notebook in vscode¶

  • You can also run Jupyter notebooks directly in VS Code

  • Open VS Code and click on the “File” menu and select “Open Folder”

  • Navigate to where you copied the notebooks for the first week

  • Click on the “L01.02_setup.ipynb” file in the left-hand toolbar

  • You should see the notebook open in VS Code

  • You can run cells by clicking the “Run Cell” button in the top right of each cell, or by pressing Shift + Enter while your cursor is in the cell

    • A menu will appear, choose the option containing .venv (the virtual environment uv sync created for you)

  • Test this out below


# some random Python code
print("That's all, folks!")
